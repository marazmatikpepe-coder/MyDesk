# MyDesk — установка на GitHub Pages (5 шагов, всё бесплатно)

## Шаг 1. Выложить сайт на GitHub Pages

1. Зайдите на github.com, войдите или зарегистрируйтесь (бесплатно, карта не нужна)
2. Нажмите **+** в правом верхнем углу → **New repository**
3. Дайте любое имя, например `mydesk` → **Create repository**
4. На странице репозитория нажмите **uploading an existing file**
   (или "Add file" → "Upload files")
5. Перетащите ТУДА ВСЕ файлы и папки из этого архива целиком, как есть
   (включая скрытую папку `.github` — просто перетащите всю распакованную папку разом)
6. Внизу нажмите **Commit changes**

7. Теперь включим сам сайт: **Settings → Pages** (в меню слева)
8. В разделе "Build and deployment" → Source: **Deploy from a branch**
9. Branch: **main**, папка: **/ (root)** → **Save**
10. Подождите 1–2 минуты, обновите страницу — вверху появится зелёная ссылка
    вида `https://ваш-логин.github.io/mydesk/` — это и есть ваше приложение

## Шаг 2. Включить бесплатные push-уведомления

1. Откройте [Firebase Console](https://console.firebase.google.com) → проект **mydesk-f83cc**
2. ⚙️ (слева внизу) → **Project settings** → вкладка **Service accounts**
3. Нажмите **Generate new private key** → подтвердите → скачается JSON-файл

4. Вернитесь в ваш репозиторий на GitHub → **Settings → Secrets and variables → Actions**
5. **New repository secret**
   - Name: `FIREBASE_SERVICE_ACCOUNT`
   - Secret: откройте скачанный JSON-файл, скопируйте **весь текст целиком** и вставьте
6. **Add secret**

## Шаг 3. Проверить, что напоминания работают

1. В репозитории откройте вкладку **Actions**
2. Слева нажмите **Check MyDesk reminders**
3. Справа кнопка **Run workflow** → **Run workflow** — запустит проверку прямо сейчас
4. Через 10–20 секунд обновите страницу — должна появиться зелёная галочка

Дальше эта проверка будет запускаться сама каждые 5 минут, бесплатно и без ограничений.

## Шаг 4. Включить уведомления в самом приложении

1. Откройте ссылку из Шага 1 на телефоне или компьютере
2. Войдите в аккаунт (или зарегистрируйтесь) внутри приложения
3. Настройки → **Push-уведомления** → нажмите, разрешите уведомления в браузере

Готово. Теперь при наступлении времени напоминания по задаче уведомление придёт,
даже если приложение полностью закрыто.

## Если что-то пошло не так

- Сайт не открывается — подождите пару минут после Шага 1, GitHub Pages включается не мгновенно
- Уведомления не приходят — проверьте, что в Шаге 3 галочка зелёная, а не красная;
  если красная, нажмите на неё — там будет написано, что не так (чаще всего неверно
  скопирован секретный ключ в Шаге 2)
- Просто напишите, что не получилось — разберёмся вместе
